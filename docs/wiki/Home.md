# VEILZERO project wiki

VEILZERO is a browser-based privacy toolkit for live face/voice transformation
and removal of supported file metadata. Its processing is designed to happen
on the user's device.

## Pages

- [Development](Development.md): setup, checks, and project structure.
- [Agile workflow](Agile-Workflow.md): issues, planning, pull requests, and
  completion criteria.

## Important limitations

VEILZERO reduces identifying signals; it does not guarantee anonymity. The
background, clothing, speech, writing style, and limitations of transformation
can still identify a person. See the project README for supported formats and
feature-specific details.
